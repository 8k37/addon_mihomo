# 3x-ui — Home Assistant add-on

Панель управления [Xray](https://github.com/XTLS/Xray-core) с поддержкой Vmess, Vless, Trojan, Shadowsocks и WireGuard.

## Первый запуск

1. Установите аддон и запустите его.
2. При первом старте 3x-ui **генерирует случайные логин, пароль и порт панели** — посмотрите их в логе аддона («Настройки → Аддоны → 3x-ui → Журнал»):

   ```
   **********************************
   Username: xxxxxxxx
   Password: xxxxxxxx
   Port: xxxxx
   **********************************
   ```

3. Откройте панель: `http://<IP-адрес-Home-Assistant>:2053/<путь из лога>`.

## Примечания

- Панель и все inbound'ы Xray работают через `host_network` — необходимые порты пробрасываются на хост напрямую (панель по умолчанию на 2053, но порт/путь меняются в самой панели).
- База данных панели (`x-ui.db`) сохраняется в `/data/addon_config/...` (маппится на `/data/x-ui` в контейнере) и переживает перезапуски и обновления аддона.
- Для корректной работы certbot/SSL в панели потребуются домен и порты, открытые наружу.

## Версия 3x-ui

Аддон собирается из официального релиза [MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui/releases). Версия задаётся в `3x-ui/build.yaml` (аргумент `XUI_VERSION`).
